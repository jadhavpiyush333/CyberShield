LINK SAFETY / 08

QR Code Scanner

Upload an image containing a QR code. Decoded URLs are passed to the configured phishing detector.

▦

Inspect a QR image

QR ANALYSIS
Supported QR decoding libraries must be installed on the server. The scanner will not visit decoded links.
ⓘ

Preview before opening

A QR code can conceal a malicious link. Review the destination before visiting it or entering sensitive information.

PROCESSINGLocal image decoding/api/scan/qr
APPLICATION SAFETY / 09

APK Static Analyzer

Inspect an Android APK archive for selected permissions, embedded URLs and basic file structure without installing or executing it.

▣

Inspect an APK

STATIC ANALYSIS
The file is inspected as an archive. It is never installed or executed. Binary Android manifests may not be fully decoded.
ⓘ

Static analysis has limits

Suspicious permissions or links are indicators, not proof of malware. A clean static result does not guarantee that an app is safe.
